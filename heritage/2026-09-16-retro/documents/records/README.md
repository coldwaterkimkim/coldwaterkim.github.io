## 실행

- 화면: http://127.0.0.1:5197/
- 작업 폴더: `/Users/kimchansu/Code/coldwaterkim-unified-feed`
- 격리 런타임: `~/.local/share/coldwaterkim/unified-feed-review`
- 검토 PocketBase: `127.0.0.1:18107`

이미 준비된 검토 DB와 로컬 인증이 필요하다. 다음 두 명령을 각각 실행한다.

```sh
python3 scripts/start-unified-review.py
```

```sh
npm run dev:unified
```

시작 스크립트는 준비된 격리 런타임만 실행하고 운영 데이터를 복사하거나 운영 서비스를 수정하지 않는다. 검토 인증과 업로드 저장소를 외부에 노출하지 않는다. 이 화면에서 작성·게시한 기록은 운영에 반영되지 않는다.

## 제품 흐름

피드 → 글쓰기 → 본문·첨부 작성 → 네 분류 중 하나 선택 → 게시 → 전체 또는 분류 필터로 확인. 임시 저장은 분류를 선택하기 전에도 가능하다. 게시된 기록의 분류를 바꿔도 주소와 최초 발행일을 유지한다.

큰 메뉴는 피드·앨범·방명록·About Me다. PC와 태블릿은 우측 세로 메뉴 및 중앙 콘텐츠만 스크롤하는 공통 틀이다. 모바일은 전체 프로필과 하단 네 메뉴를 보여준다. 낮은 PC 화면의 전체 프로필 표는 대화상자로 열 수 있다. 페이지뷰 전환·Ask Me·프로그램실은 폐기한다. 프로젝트는 피드의 소개 글 분류다.

## 보존 범위

- 기존 글방·나으 하루·나사잡 원문, 공개 상태, 최초 발행일, 기존 주소, 사진 식별값과 앨범 태그.
- 사진 스와이프와 크롭, 사진별 코멘트 및 빈 코멘트의 공통 본문 표시.
- ChatGPT 공유 snapshot, YouTube, 영상·오디오·파일 첨부.
- 기존 업로드 전송 경로와 원본 파일. 크롭·분류·코멘트 변경은 원본 재업로드 사유가 아니다.
- 복잡한 기존 HTML의 보존 원문 영역. 내부 문단을 자동으로 일반 텍스트로 변환하지 않는다.
